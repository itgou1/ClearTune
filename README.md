# ClearTune（轻调）

一款为私人音乐库设计的原生 Android 播放器。

ClearTune 连接你自己的 Navidrome 或 OpenSubsonic 兼容服务器，把浏览、播放、歌单、下载和音质设置整理成轻量、清晰的日常听歌体验。它不提供云音乐内容，也不要求注册 ClearTune 账号。

当前源码版本：`1.4.0` · [本次更新说明](release-notes/v1.4.0.md) · [已发布安装包](https://github.com/itgou1/ClearTune/releases)

## 产品亮点

### 打开就有想听的音乐

首页以“今天听什么”为标题，从上到下组织日常听歌入口：

- **发现音乐**：宽幅卡片配四张封面，点击进入发现页；曲库不足 20 首时不显示该区域
- **随便听听 / 好久不见、常听精选**：两张并排卡片，使用前后叠放的双封面，播放标识嵌入主封面；点击整张卡片即可播放，不必寻找单独的小按钮。左侧内容会根据播放记录切换，没有可用歌曲时卡片不可播放
- **最近添加**：按专辑内歌曲的最新入库时间展示最近 20 张专辑，老专辑补充歌曲也会前移；缺少歌曲时间时回退到专辑入库时间。进入专辑后，近 30 天入库的歌曲标记为“新加入”，不改变原有曲序

首次进入时内容轻量渐入，卡片按压时有缩放反馈；返回首页不重复播放入场动画。推荐只来自你自己的曲库，不混入广告或平台推广内容。

### 喜欢、画像与歌单集中在“我的”

- 听歌画像与“我喜欢的音乐”并排展示，便于快速进入
- 歌单直接列在当前页面，数量显示在“歌单”标题旁，不再设置重复的歌单汇总快捷入口
- 离线与下载使用紧凑入口，减少页面占用；设置入口保留在页面右上角
- “我喜欢的音乐”记住上次排序方式；收藏和歌单中的歌曲展示专辑封面，缺图时使用默认封面，不展示无意义的曲目编号

### 从曲库到播放，操作更顺手

- 按专辑、艺术家、歌曲、流派或服务器文件夹浏览；流派可直接进入对应歌曲列表
- 搜索会先从本地缓存即时显示结果，再合并服务器结果，并支持继续加载更多内容
- 音乐库显示当前同步阶段和上次成功同步时间，连接异常时仍保留本地内容
- 快速喜欢歌曲、下一首播放、加入歌单、下载或查看歌曲详情
- 音乐库歌曲、专辑和艺术家歌曲列表支持长按进入批量选择，不增加常驻按钮；可全选并加入已有歌单或新建歌单，自动跳过重复歌曲，失败时保留选择
- 歌单与 Navidrome 同步，支持搜索选歌、按喜欢或最近播放筛选，以及批量添加和移除歌曲
- 迷你播放器便于跨页面控制播放；批量选择时临时收起，音乐继续播放，退出选择后恢复
- 播放队列支持长按拖动排序，并提供顺序、随机和循环模式
- 支持同步歌词、歌曲格式与码率信息，以及播放进度快速调整
- 歌词为空时会重新查询服务器；已有歌词先显示本地副本，超过 24 小时后台更新。歌词界面右下角“⋯”可手动刷新，网络失败时保留已有内容
- 主播放器、歌词界面与迷你播放器的超长歌名在播放中缓慢滚动；暂停时停在当前位置，继续播放后接着滚动，切歌从头开始。主播放器长按标题可查看完整歌曲信息
- 可在设置中连接自己的 Music Tag Web，通过“音乐库 → 歌曲 → 更多 → 音乐标签”或主播放器右下角更多菜单维护单曲。打开后读取服务器原文件标签，可直接编辑，也可刮削并选择字段填入表单；统一点击“保存修改”后仅写入实际变化的字段。退出时可保留当前会话内的草稿。原文件保存与曲库刷新分别反馈状态。服务需挂载同一音乐库，目录映射在设置中配置；本版不支持清空标签、重命名或批量改写
- Music Tag 配置成功后显示连接状态，退出连接后才能重新配置。Navidrome 默认可能返回虚拟歌曲路径，应用会使用当前音乐账号通过 Navidrome 原生接口按歌曲 ID 获取真实文件路径，再进行目录映射；不会根据标题猜测目标文件。读取失败时可查看目标路径与具体错误原因
- Music Tag V1 不支持原始封面校验时，会展示所选图片与文件读回封面对照，确认一致后再刷新曲库；检查保存结果不会重复写入文件

### 离线也能完整听歌

ClearTune 可以下载服务器中的原始音乐文件，并支持暂停、继续和断点续传。下载列表与后台任务同步，显示实际进度，以及等待网络、等待调度、自动重试或失败原因；服务器拒绝下载、返回非音频内容、本地空间不足时会给出明确提示。

“仅使用 Wi-Fi 下载”按非计费网络判断：被系统标记为计费的 Wi-Fi 也会等待。修改网络限制后，对已有未完成任务生效。取消下载任务与删除已完成文件使用不同操作文案，并在删除前再次确认；下载完成后可直接使用本地文件播放。

播放缓存与主动下载分开管理：缓存上限可选 **512 MB、1 GB、2 GB、4 GB**，默认 512 MB，达到上限后淘汰旧缓存；主动下载的离线歌曲不属于这项播放缓存额度。

播放优先使用有效的已下载文件。断网时优先使用当前音质的缓存；当前音质缓存不完整而其他音质有完整缓存时，使用完整缓存继续播放。断网不会把移动网络音质自动切换成 Wi-Fi 的原始音质，重新启动也会保留此前使用的音质策略。

封面图片的内存、磁盘缓存按服务器与账号隔离；“清理图片与临时缓存”统一清理图片库缓存和临时文件，不删除离线音频、离线封面或歌词。下载歌曲时会同时保存一份封面，供列表、播放器和离线播放通知使用；已有下载会按下载网络设置后台补齐封面。封面获取失败不影响音频下载，联网后有限重试，重新进入应用可再次补齐。删除下载时，共用专辑封面会保留到没有下载任务引用它为止。

歌词保存在账号专属数据库中，并按服务器、用户名和歌曲 ID 查询，不是公共目录中的 `.lrc` 文件。在线播放音频缓存按服务器、账号、歌曲和音质区分；不同账号共用容量上限，但不复用缓存内容。图片缓存不占用 512 MB～4 GB 的音频缓存额度。

通过 Music Tag 修改音乐文件后，应用会等待服务器曲库同步，再更新歌词、封面和播放元数据。已下载音频仍是修改前的独立副本，需要时可重新下载；尚未完成的下载不会继续复用旧文件片段。

### 音质由你决定

- Wi-Fi 下默认保留服务器提供的原始音质
- 移动网络可选择 128、192、320 kbps，或继续使用原始音质
- ReplayGain 音量平衡，减少不同专辑之间忽大忽小的听感
- 提供易用的均衡器预设，也支持自定义调节

### 贴近日常 Android 使用习惯

界面采用 Material 3，支持浅色、深色和跟随系统主题，并配有沉浸式系统栏、自然的页面动效和无封面时的统一占位图。播放、下载和操作结果会在当前页面及时反馈。

专辑、艺术家和歌单详情分别保留所属页面的数据与加载任务。返回手势松手并由系统确认后才切换页面；取消手势时保留当前歌曲列表、滚动位置和选择状态。耳机与系统媒体控制的“上一曲”直接切歌，与应用内按钮保持一致。

## 为私人音乐库而设计

<p align="center">
  <img src="screenshots/private-library.png" alt="手机直连私人音乐服务器的隐私体验插图">
</p>
<p align="center"><sub>隐私关系示意图；不展示账号、服务器地址、真实封面或曲目信息。</sub></p>

- 应用连接你主动配置的音乐服务器和可选的 Music Tag 服务，不内置公共服务器或共享账号；主动刮削会通过 Music Tag 查询所选元数据来源，候选封面可能从对应图片地址加载
- 不提供 ClearTune 云账户，曲库和播放内容不会上传到 ClearTune 服务
- 登录凭据由 Android Keystore 保护并保存在设备本地
- 音乐库、下载、队列和搜索历史等本地数据按服务器与账号隔离；退出账号时停止播放、清空当前队列并取消后台下载
- 喜欢、歌单和播放记录只在本地设备与你的音乐服务器之间处理或同步
- 不接入广告、用户行为统计 SDK 或大模型服务
- 开启更新检查时，仅访问公开的 GitHub Releases 接口

## 适合谁

ClearTune 适合已经拥有 Navidrome 或其他 OpenSubsonic 兼容服务器，希望在 Android 上获得原生、轻量、重视离线和音质体验的用户。

它不是在线音乐平台，不提供歌曲版权内容或公共曲库；使用前需要准备一个可访问的私人音乐服务器。目前客户端面向 Android 设备。

## 快速开始

1. 从项目的 [GitHub Releases](https://github.com/itgou1/ClearTune/releases) 下载并安装最新版 APK。
2. 准备一个可访问的 Navidrome 或 OpenSubsonic 兼容服务器。
3. 打开 ClearTune，填写服务器地址、用户名和密码。
4. 连接成功后，即可浏览曲库、同步喜欢与歌单并开始播放。

### 从 1.3.5 升级至 1.4.0

正式版沿用原有签名，可覆盖安装并保留账号、设置、下载和播放队列。Music Tag 为可选功能，升级后在设置中连接自行部署的服务并配置目录映射；建议先选择一首可核对的歌曲验证原文件路径与修改结果。歌词旧的空缓存会在联网播放时重新请求，也可从歌词界面右下角“⋯”手动刷新。详情见 [1.4.0 更新说明](release-notes/v1.4.0.md)。

### 从 1.3.3 / 1.3.4 升级至 1.3.5

1.3.5 沿用现有账号数据库、设置、队列与离线音频目录，不要求重新下载已有歌曲。从 1.3.3 升级时仍会应用 1.3.4 的封面缓存改进：首次显示可能需要重新加载，已有离线歌曲按下载网络设置补齐封面，封面失败不影响音频播放。

1.3.5 已完成离线冷启动、保留数据覆盖安装和系统媒体按键等针对性模拟器验收。测试范围与真机验收边界见 [1.3.5 更新说明](release-notes/v1.3.5.md)。

### 从 1.3.2 及更早版本升级

1.3.3 起启用账号隔离。旧版无法确认归属的本地数据不会自动读取或迁移，也不会主动删除。请在升级前联网完成尚未同步的修改；升级后重新同步音乐库，并重新下载需要离线收听的歌曲。服务器上的音乐、收藏与歌单不受影响，旧本地队列、播放记录和搜索历史不会自动迁移。

正式版使用原有签名，可覆盖安装，无需卸载。Debug 版可能因签名不同无法覆盖，请勿为升级贸然卸载。

<details>
<summary>开发者构建信息</summary>

本项目使用 JDK 17 和 Android SDK 37，并通过 Gradle Wrapper 固定构建工具版本。

```bash
git clone https://github.com/itgou1/ClearTune.git
cd ClearTune
```

macOS / Linux：

```bash
./gradlew :app:assembleDebug
```

Windows：

```powershell
.\gradlew.bat :app:assembleDebug
```

运行本地单元测试：

```bash
./gradlew testDebugUnitTest
```

Debug APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。正式版由仓库的 GitHub Actions 工作流签名并发布到 GitHub Releases；签名文件和密码不得提交到仓库。
