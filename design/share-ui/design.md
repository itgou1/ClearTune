# ClearTune 分享功能与 UI 设计

设计日期：2026-09-24。状态：首版 Android 分享功能已接入；图中的音乐、账号、链接和访问量均为演示数据。当前使用系统分享，不接入微信开放平台。

## 1. 确定的范围

- 单曲：歌曲已有更多菜单、播放器已有更多菜单中新增「分享歌曲」。
- 专辑：详情页顶栏右上角直接新增分享图标，不新建更多菜单。
- 歌单：详情页顶栏右上角直接新增分享图标，不把分享藏进更多菜单。其他已有操作保持原来的位置。
- 管理入口：「我的」页面最下方的「分享」栏目 →「我的分享」。当前账号没有分享记录时，整个栏目隐藏。
- 接收者打开 Navidrome 自带公开网页播放，无需 ClearTune 或音乐服务器账号。
- 第一版包含创建链接、复制链接、系统分享、查看我的分享、修改说明和有效期、取消分享。

## 2. 链接和微信

### 第一版：系统分享链接

链接创建成功后展示完整分享文案预览，提供「复制分享内容」和「分享歌曲／专辑／歌单」。后者调用 Android 系统分享面板；微信注册了可处理的分享入口时，可在面板中选择微信，由用户选择朋友/群并发送。系统面板由 Android 与已安装应用决定，ClearTune 不固定接收目标，也不保证每台设备都出现微信。预览内另保留「仅复制链接」。

「复制分享内容」、界面预览和系统分享正文使用同一份文案：类型和名称、已知的艺术家或歌曲数量、可选分享说明、单独一行的公开收听链接及已知有效期。未知字段省略，歌单不使用其中第一首歌曲的艺术家。只在用户主动点击「仅复制链接」时复制裸 URL。Android 分享面板继续附带标题和临时只读封面 URI；取不到封面时使用默认封面。即使接收应用不显示卡片，正文也包含足够的音乐信息。发送取消后仍保留已经创建的分享记录；创建成功和发送成功是两种状态。示例域名不是可播放服务。微信内打开效果、HTTPS 和域名可达性需要真机验证。

## 3. 统一创建流程

详情页/单曲菜单 → 分享底部面板 → 生成分享链接 → 同一面板显示链接与渠道。

创建面板内容：

1. 标题「分享歌曲 / 分享专辑 / 分享歌单」和关闭按钮。
2. 64dp 封面、名称、作者/艺术家、歌曲数量。名称最多两行。
3. 分享说明：可选，默认空，占位文案「写一句推荐语（可选）」。客户端暂定最多 200 字。
4. 有效期：1 天 / 7 天 / 30 天，默认 7 天。时间以创建成功时服务器返回的绝对到期时间为准，使用设备时区显示。
5. 歌单专属说明：「以生成链接时读取到的歌曲为准，后续修改不会同步。」
6. 通用提示：「拥有链接的人可在有效期内访问，无需登录。」
7. 主按钮「生成分享链接」。只有主动点击才创建服务器记录，打开面板不创建。

生成中按钮显示「正在生成…」，禁用重复提交。服务端成功后即记下 shareId 与返回 URL；取消渠道选择不删除记录。网络超时且结果不明确时先刷新分享列表核对，不能自动重复创建。

成功面板内容：成功图标与「链接已生成」、内容摘要、绝对到期时间、完整分享文案预览、主按钮「分享歌曲／专辑／歌单」、次按钮「复制分享内容」、轻量入口「管理此分享」。复制后给出「分享内容已复制」；预览内的「仅复制链接」单独反馈「链接已复制」。不自动跳转微信或自动发送。

同一面板重复复制/转发使用原链接。重新从详情入口发起新创建可生成独立分享，避免全局去重错误复用不同说明/到期时间的记录。

## 4. 分享对象和歌单快照

| 对象 | 创建策略 | 内容语义 |
| --- | --- | --- |
| 歌曲 | createShare(id=songId) | 单曲公开分享 |
| 专辑 | createShare(id=albumId) | 分享专辑对象；实际内容由服务器解析，不宣称固定快照 |
| 歌单 | 获取完整当前 getPlaylist 结果，再以多个歌曲 id 创建 | 歌曲成员快照；保留原始顺序提交，顺序和重复项的实际呈现需 Navidrome 版本联调 |

歌单快照只固定选中的歌曲 ID，不复制音频文件。歌曲被删除、权限或服务端库发生变化，可能影响访问。创建前重新取完整歌单，不能把 UI 当前筛选/分页内容当作整份歌单。空歌单不可分享。超大歌单需要验证 POST 支持和代理请求大小；不静默截断或拆成多条分享。第一版不提供随歌单自动更新的链接。

创建成功后的摘要、分享正文和管理页统一使用本次实际提交的歌曲数量，并保存这份数量用于后续重新加载。分享面板打开后歌单增删歌曲，不沿用打开面板时的旧数量；若歌单被清空或未读取完整，则不创建链接。

## 5. 我的分享

「我的」页面在歌单列表之后显示「分享」栏目和「我的分享」入口，副标题显示当前账号的链接数量与「管理有效期」。进入「我的」时刷新当前账号的分享列表；列表非空才渲染栏目标题和入口。删除最后一条分享后，返回「我的」时整个栏目消失。设置页面不再显示该入口。

列表标题「我的分享」，副标题「当前账号创建的链接」，按创建时间倒序。无需另加统计面板、搜索或筛选。每行/卡片展示封面、名称、对象类型、数量（可知时）、生效中或已过期、到期时间。可展示服务端提供的访问次数，但必须标为「访问」，不解释为播放次数或独立人数。

点记录打开管理详情，提供：

- 生效中：复制分享内容、分享歌曲／专辑／歌单、编辑分享、取消分享；预览内另保留「仅复制链接」。
- 已过期：显示到期信息，优先「编辑有效期」；过期状态不提供误导性的正常转发主按钮。延长有效期成功后，同一链接重新有效。
- 编辑面板：说明 + 明确的新有效期，保存时只调用 updateShare，保留链接 ID。无法读取原始对象信息时用服务端 description/entry 显示，不能猜测为歌单。
- 取消分享：二次确认「取消分享后，这个链接将无法访问。已发送的消息不会被删除。」按钮「保留链接 / 取消分享」。成功调用 deleteShare 后从当前列表移除，不杜撰服务端不存在的“已取消”历史。

撤销后重新分享会创建新的链接；当前已经缓存/下载的内容无法由撤销操作追回。此说明放在设计实现约束，不增加用户日常弹窗。

列表以服务端为准，与 Navidrome 网页端创建/修改/删除结果同步。管理员可能看到所有记录，ClearTune 的「我的分享」仍按创建者过滤当前账号。服务器/账号切换清除上一账号状态，不串用链接。

## 6. 状态和错误

| 状态 | 呈现与操作 |
| --- | --- |
| 尚无分享 | 「我的」页隐藏整个分享栏目；若已停留在管理页，仍显示「还没有分享」空状态 |
| 加载失败 | 保留已有内容，显示失败原因和重试 |
| 服务器禁用/不支持分享 | 「当前服务器未开启分享」或「当前服务器不支持分享」，不给虚假 URL |
| 空歌单 | 「歌单还没有歌曲，添加歌曲后再分享」 |
| 歌单读取失败 | 不创建部分分享，提供重试 |
| 断网 | 保留说明草稿，提示联网后生成；已知有效链接仍可复制 |
| 分享失效/对象被删除 | 提示无法访问，管理页重新读取服务器状态 |
| 没有微信或系统面板无微信入口 | 用户可复制链接到可用渠道；不伪造微信发送成功 |
| 内网地址 | 根据已知内网地址给轻提示「对方需要能访问你的音乐服务器」，不把本机访问成功当成公网验证 |

## 7. UI 规格

沿用 ClearTune Material 3，不做详情页改版。浅色背景 #F5F3FF、surface #FFFBFF、主色 #4965A1、主色容器 #DCE5FF；深色映射沿用 Theme.kt。页面横向 20dp；内容圆角 18–24dp，底部面板顶部 28dp；主按钮 48–52dp；图标视觉 24dp，点击范围至少 48dp。

专辑/歌单右上角是无常驻底色的 share 图标，语义「分享专辑/分享歌单」。进入批量选择时由选择栏接管顶栏，不混入整个对象的分享动作。封面保留现有约 220dp 的详情页展示尺寸。

底部面板可滚动，键盘弹出不遮挡生成按钮；示意图为静态全展开状态。全程不停止音乐，遮罩覆盖下层操作并管理焦点，关闭后回到触发位置。支持系统返回关闭面板和字体放大。

设计稿页面：01 专辑入口、02 歌单入口、03 单曲菜单、04 创建歌单分享、05 生成成功、06「我的」入口、07 我的分享、08 管理详情、09 编辑、10 取消确认，以及无分享与服务器禁用状态。交互稿支持页面切换和核心流程点击；所有操作只改变演示状态。静态图与交互稿保留早期设计方案，部分按钮文案和菜单顺序尚未同步后续调整；当前行为以本文和 Android 实现为准。

## 8. 接入结构与验收

新增 Share DTO / OpenSubsonic API 四个端点、ShareRepository、ShareViewModel、统一 ShareSheet 与 MySharesScreen。现有 DetailScaffold 已有 actions 槽位，专辑/歌单直接传入分享动作；「我的」页面按当前账号分享数量显示管理入口。不要共享专辑与歌单的异步页面状态。

保存本机创建时的辅助 metadata（按服务器+账号+shareId 隔离），便于识别歌单名、对象类型和封面；服务端记录永远是存在性、URL、说明和期限的权威。其他设备建立的记录没有类型信息时用「音乐分享」与服务端条目回退，不反推错误类型。

客户端不拼接鉴权播放地址；只分发服务器返回的分享 URL，不附带用户名、密码、salt 或 token。服务器错误码与 HTTP 成功中的 Subsonic 业务失败都必须处理。记录日志时隐藏公开链接中的分享标识。

首版不在 UI 提供下载开关，实际下载权限沿用服务器行为。若后续要求「仅试听」，需要验证 Navidrome 版本对 downloadable 参数的支持，不能只隐藏按钮就宣称禁止下载。

实施验收：真实 Navidrome 对单曲/专辑/完整歌单创建、匿名网页访问、期限修改、取消后旧 URL 失效、微信真机文字链接流程、账号隔离、空歌单、关闭分享、超时重试、长名称/大字号/深色主题。先查安装服务器版本，不将 master 源码行为视为所有已发布版本能力。
