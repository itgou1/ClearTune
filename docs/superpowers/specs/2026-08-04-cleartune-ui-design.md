# ClearTune 主要页面 UI 设计

日期：2026-08-04

关联规格：[ClearTune Android 音乐播放器设计](./2026-08-03-cleartune-android-music-player-design.md)

## 1. 设计目标

ClearTune 的界面借鉴 Apple Music 的信息层级、留白、封面主导和沉浸式播放体验，同时遵循 Android 的返回、长按多选、系统手势和自适应布局习惯。设计不复制 Apple 的商标、SF Symbols、SF Pro、专有插图、页面截图或其他品牌资产。

界面服务于个人本地/WebDAV 音乐库，重点是：

- 让用户快速找到、播放和管理自己的音乐；
- 在资料库页面保持安静、稳定和清晰；
- 只在完整播放页使用封面驱动的沉浸式颜色；
- 不用推荐、广播或在线内容填充页面；
- 不为功能较薄的歌单、下载和设置创建一级底部入口。

## 2. 选定的视觉方向

采用“编辑式极简”方向：大标题、明确分区、充足留白、封面主导，普通歌曲行不套卡片。没有采用全局封面沉浸式方案，以避免列表可读性不稳定；没有采用高密度工具型方案，以免界面失去音乐产品的内容感。

### 2.1 色彩

固定 ClearTune 品牌色，不跟随 Material You 动态换色。

| 角色 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 页面背景 | `#F7F7F9` | `#0C0C0E` |
| 主要表面 | `#FFFFFF` | `#1A1A1E` |
| 主要文字 | `#161617` | `#F5F5F7` |
| 次要文字 | `#68686D` | `#A7A7AD` |
| 分隔线 | `#E4E4E7` | `#2B2B30` |
| 品牌主色 | `#D63A52` | `#FF6678` |

品牌色用于主要按钮、收藏、进度、可点击强调和重要状态，不用于大面积普通页面背景。

完整播放页从封面提取两至三个低饱和颜色生成渐变，再叠加明暗遮罩。前景色根据背景亮度自动选择，并保证正文和交互控件达到 WCAG AA 对比度。用户可以在设置中关闭播放页动态背景，关闭后使用稳定的中性渐变。

### 2.2 字体与排版

使用 Android 系统字体，不捆绑或仿制 SF Pro。

| 用途 | 建议规格 |
| --- | --- |
| 页面大标题 | 32sp，Bold |
| 滚动后顶部标题 | 20sp，SemiBold |
| 分区标题 | 22sp，Bold |
| 条目主标题 | 16sp，Medium |
| 正文 | 16sp，Regular |
| 次要信息 | 13–14sp，Regular |
| 同步歌词当前行 | 28sp，Bold |

页面标题随滚动从大标题收拢到顶部栏。所有文本支持系统字体放大至 200%，不得依靠固定高度裁切标题或按钮。

### 2.3 间距、圆角与图标

- 页面水平边距：20dp；
- 基础间距网格：4dp/8dp；
- 分区间距：28dp；
- 专辑封面圆角：10dp；
- 弹层顶部圆角：28dp；
- 最小触控区域：48dp；
- 图标：Material Symbols Rounded；
- 普通列表行使用留白和细分隔线，不使用卡片阴影。

## 3. 导航模型

### 3.1 手机

手机端不使用底部导航。资料库是唯一一级目的地：

```text
资料库
├─ 歌曲
├─ 专辑
│  └─ 专辑详情
├─ 歌手
│  └─ 歌手详情
├─ 歌单
│  └─ 歌单详情
├─ 文件夹
├─ 已下载
├─ 搜索
└─ 设置
   ├─ 音乐来源
   ├─ 下载与存储
   ├─ 外观
   └─ 关于
```

二级及更深页面显示返回按钮并支持 Android 返回手势。搜索和设置从资料库标题右侧进入。迷你播放器固定在系统手势安全区上方，不占用独立导航层。

### 3.2 平板与横屏

平板不增加底部导航。资料库分类作为左侧列表，右侧显示当前分类或详情，采用列表—详情双栏结构。完整播放页在横屏和平板上使用左侧封面/控制、右侧歌词或队列布局。

## 4. 公共组件

### 4.1 顶部栏

根页面显示 32sp“资料库”大标题，以及搜索、设置按钮。二级页面显示返回按钮、页面标题和排序/更多操作。滚动后大标题收拢，但主要操作始终可访问。

### 4.2 歌曲行

标准歌曲行高度约 64dp：

```text
[48dp封面]  歌曲名称                    [更多]
            歌手 · 专辑
```

离线歌曲显示小型下载状态；来源不作为常驻徽章，只在详情、筛选或更多菜单显示。不可用歌曲降低文字强调并显示明确状态。长按进入 Android 原生多选模式。

### 4.3 封面占位

无专辑封面时使用一张固定的简洁唱片/声波矢量占位图，浅色和深色模式各有对应配色，不生成随机图案。

无歌手图片时，从内置 6–8 张简洁抽象人物矢量头像中选择。头像采用圆形裁切、中性灰与低饱和珊瑚辅助色，不显示文字首字母。根据稳定歌手 ID 确定头像索引，同一歌手在不同会话和设备布局中保持一致。真实歌手图片以后可以直接覆盖占位头像。

### 4.4 按钮与菜单

每个区域最多一个高强调实心主按钮；次要操作使用文字按钮、图标按钮或低强调色块。歌曲、专辑和歌单的扩展操作统一进入底部弹层，操作顺序保持一致：播放下一首、加入队列、加入歌单、收藏、下载/删除下载、查看详情。

## 5. 资料库首页

资料库首页是打开应用后的默认页面：

```text
资料库                                  [搜索] [设置]

歌曲                                          >
专辑                                          >
歌手                                          >
歌单                                          >
文件夹                                        >
已下载                                        >

最近添加                              查看全部
[封面] [封面]
专辑名 专辑名
歌手   歌手

最近播放                              查看全部
[封面] [封面] [封面] →

音乐来源
本地音乐 · 家庭音乐库
```

- 分类入口使用简洁列表，不使用六宫格卡片；
- 最近添加采用双列专辑封面网格，首屏最多显示四张；
- 最近播放采用横向封面列表，可包含歌曲、专辑和歌单；
- 已下载入口可以显示歌曲数和占用摘要；
- 正常状态不显示同步提示；同步中显示细进度条，失败时显示一行可重试提示；
- 本地和 WebDAV 音乐统一呈现，普通页面不持续暴露来源标签。

## 6. 资料库分类页

### 6.1 歌曲

- 顶部显示歌曲数量和总时长；
- 提供播放全部和随机播放；
- 支持按标题、歌手、专辑、最近添加排序；
- 支持全部、本地、WebDAV、已下载筛选；
- 长按多选后可批量加入歌单、下载或移出下载；
- 右侧字母快速索引仅在按标题或歌手排序且数据量足够时显示。

### 6.2 专辑与专辑详情

手机使用两列自适应封面网格，封面下显示专辑名和“歌手 · 年份”。更宽屏幕增加列数，但封面保持等宽正方形。

专辑详情顶部展示大封面、专辑名、歌手、年份、歌曲数、播放和随机播放。歌曲列表显示音轨编号，不重复展示封面。顶部可以使用封面主色的极浅渐变，正文仍使用中性背景。

### 6.3 歌手与歌手详情

歌手列表使用圆形真实图片或稳定分配的默认头像。歌手详情显示同一头像、歌手名和播放按钮，内容分为热门歌曲与专辑。首版不展示从网络虚构或抓取的歌手简介。

### 6.4 文件夹

首层按设备本地和各 WebDAV 来源分组。进入目录后显示简洁路径面包屑、文件夹名称、音频数量和歌曲行。支持播放当前文件夹、随机播放，以及下载整个 WebDAV 文件夹。普通界面不显示完整服务器 URL。

### 6.5 歌单与歌单详情

歌单页顶部使用“＋”创建歌单，不使用悬浮按钮。收藏作为固定歌单排在首位。列表展示四宫格封面、歌单名和歌曲数。

详情页使用封面拼图、大标题、播放和随机播放；歌曲可以长按拖动排序。移除歌曲只影响歌单，不删除本地或远程文件。

### 6.6 已下载

顶部显示歌曲数量和存储占用，可以按歌曲、专辑或下载时间查看。进行中的任务固定在已完成内容上方。删除操作只移除离线副本，远程媒体记录、收藏和歌单关系继续保留。

## 7. 搜索

点击资料库右上角搜索进入全屏页面，输入框自动获得焦点。搜索 Room 中已有的歌曲、专辑、歌手和歌单，不依赖 WebDAV 实时网络。

默认综合结果按类型分区，每区展示少量结果及“查看全部”。筛选使用紧凑的横向标签。无输入时显示最近搜索；无结果时提示检查拼写或重新同步，不显示通用失败插图。

## 8. 播放体验

### 8.1 迷你播放器

迷你播放器固定在系统手势区上方，高度约 68dp，顶部是一条当前播放进度线。内部包含 48dp 封面、歌曲名、歌手、播放/暂停和下一首。

- 点击展开完整播放页；
- 左右滑动切歌；
- 播放失败时用错误状态替代进度线，并允许查看原因；
- 没有播放记录时完全隐藏，不保留空白区域。

### 8.2 完整播放页

播放页从底部展开并占满屏幕：顶部为收起、“正在播放”和更多；中间为大封面、歌曲名、歌手、收藏；下方为进度、上一首、播放/暂停、下一首、随机、循环、下载、歌词和队列。

封面宽度约为屏幕宽度的 78%，最大 360dp。标题和歌手左对齐，歌手名可以进入歌手详情。播放按钮是最大的交互焦点。播放时封面放大至 100%，暂停时缩小到 96%，过渡约 250ms。向下滑动收起，左右滑动封面切歌，同时保留明确按钮。

### 8.3 歌词

歌词模式替换封面主区域。当前行使用约 28sp 高对比文字，相邻歌词降低强调。当前行保持在屏幕中部偏上；点击歌词行跳转时间。用户手动滚动后暂停自动跟随，并显示“回到当前歌词”。无时间轴歌词使用全文模式；无歌词显示明确说明。底部保留紧凑进度和播放控制。

### 8.4 队列

队列为全屏内容页。当前歌曲固定在顶部，后续歌曲显示拖动手柄；点击立即播放、拖动排序、左滑移出队列。顶部显示随机和循环状态，底部折叠播放历史。首版不显示自动推荐或无限播放。清空队列需要确认，但不停止当前歌曲。

## 9. 首次使用与音乐来源

### 9.1 首次空状态

首次启动直接进入资料库空状态，不使用多页引导。页面显示简洁 ClearTune 图标、说明、“扫描本地音乐”主按钮和“添加 WebDAV”次要操作。请求音频权限前先说明用途；拒绝权限后仍可使用 WebDAV。

### 9.2 来源列表

音乐来源位于设置中，按“设备本地”和“WebDAV”分组。每行显示名称、歌曲数、最后同步时间或错误状态。来源详情包含根目录、统计、同步进度、立即同步、取消、编辑、重新选择目录和删除。

### 9.3 新增 WebDAV

流程为：填写名称、服务器地址、用户名和密码；测试连接；连接成功后选择根目录；保存并开始首次同步。测试按钮内部显示进度。URL、鉴权、TLS 和目录权限错误分别显示。HTTP 地址需要显式确认并持续显示不安全警告。

## 10. 下载与设置

### 10.1 下载状态

界面统一使用等待下载、正在下载、等待 Wi-Fi、下载失败、已完成和远程文件已有更新六种状态。进行中的任务显示封面、文件名、已下载/总大小、进度和暂停/取消；失败任务显示安全的简短原因和重试。

### 10.2 存储

临时缓存和离线下载必须分别展示：

```text
临时播放缓存        328 MB         [清除]
离线下载            4.2 GB         [管理]
仅通过 Wi-Fi 下载                  [开关]
缓存上限            512 MB             >
```

清除缓存不得删除离线歌曲。删除全部下载需要确认。

### 10.3 设置结构

设置仅包含音乐来源、播放、下载与存储、外观和关于。播放设置包含恢复上次队列和耳机断开暂停；外观包含跟随系统/浅色/深色，以及播放页动态背景开关。不得加入没有实际行为的占位设置项。

## 11. 状态与错误呈现

- 没有歌曲：提供扫描本地和添加 WebDAV；
- 分类为空：解释该分类暂无内容；
- 同步中：资料库顶部显示细进度，已有内容仍可使用；
- 同步失败：保留旧内容并显示可重试提示；
- 播放失败：区分文件不存在、网络不可用和需要重新登录；
- 空间不足：显示所需空间和当前可用空间；
- WebDAV 认证失效：直接进入对应来源的凭据修改页；
- 危险操作：使用确认对话框；
- 普通失败：优先页面内提示或 Snackbar，不滥用弹窗；
- 加载列表：使用保持布局稳定的骨架，不闪烁整页进度圈。

## 12. 动效与无障碍

- 页面进入/返回：遵循 Android 导航方向，时长 200–300ms；
- 迷你播放器到完整播放页：封面和文字连续过渡；
- 开启系统减少动态效果后，关闭封面缩放和大幅共享过渡；
- 所有触控区域至少 48dp；
- 动态背景上的文字和控件达到 WCAG AA；
- TalkBack 读取歌曲行的顺序为歌曲名、歌手、下载/可用状态、更多操作；
- 封面、头像、状态图标和图标按钮具备语义标签；
- 颜色状态同时通过文字或图标表达，不只依赖颜色。

## 13. UI 验收标准

- 手机端不存在底部导航，资料库是唯一根页面；
- 迷你播放器不与系统手势区重叠，并在所有二级页面保持可用；
- 浅色、深色和播放页动态背景下文字均清晰；
- 歌曲、专辑、歌手、歌单、文件夹、下载和搜索具有完整的正常、加载、空和错误状态；
- 默认歌手头像稳定、简洁且不会因重启随机变化；
- 字体放大到 200% 时主要内容和操作不被裁切；
- TalkBack 可以完成来源添加、媒体浏览、播放、队列调整和下载管理；
- 平板采用双栏布局，不把手机界面简单拉伸；
- UI 不使用 Apple 商标、字体、图标或专有素材。
