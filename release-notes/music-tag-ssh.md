# 标签服务的 SSH 按需连接

标签服务保留直接 HTTP/HTTPS 连接，新增 SSH 隧道模式。Navidrome 不改变连接方式。

## 使用

在“Music Tag 服务”中选择“SSH 隧道”，填写 SSH 主机、端口、用户名及密码或导入私钥。私钥支持库可解析的 PEM/OpenSSH 格式，导入上限为 64 KB，可填写私钥口令。Music Tag 账号独立填写。

内部服务地址使用服务器本机 HTTP，例如 `http://127.0.0.1:8002`，支持路径前缀。当前仅允许回环目标，避免将服务器到其他主机的明文 HTTP 误称为端到端保护。

首次测试在认证前停止并显示 SHA256 主机指纹。通过云服务器控制台或可信管理员核对后，选择“已核对，信任并继续”。测试成功才保存配置；以后每次连接校验已记录的主机密钥。指纹变化时拒绝连接，需要独立核实后移除旧配置并重新配置。

保存后的“配置已验证”代表上次测试通过，不代表当前在线。读取、刮削、获取歌词、保存或核验时按需建立连接，编辑期间复用已认证连接。一次完整操作结束后开始计时，空闲 60 秒释放；新操作取消空闲计时。保存和核验属于同一次完整操作，期间不会因空闲超时断开。本地表单修改不会单独建立连接。

离开编辑页面、打开连接设置或 APP 进入后台时释放空闲连接；仍在执行的保存和核验完成后再释放。返回页面不自动重连，下次请求时连接。失败或取消会释放连接，写请求不自动重放。页面内操作串行执行，旧页面排队的操作不能在重新进入后建立连接。测试配置仍使用短连接，测试结束立即释放。SSH 失败不会降级为 HTTP。

测试可用后，服务器管理员可关闭 WebTag 8002 公网入站，仅允许本机访问；推荐使用限制转发目的地的专用 SSH 账号。APP 不修改服务器安全组或 SSH 配置。

## 存储与兼容

- `MusicTagSettingsCodec` 为加密载荷增加 v2 标记，兼容原来的七字段载荷；旧数据保持直接连接及既有 HTTP 授权。
- 整份配置继续通过 `CredentialCipher` 的 Android Keystore AES-GCM 加密保存，包括 SSH 密码、私钥、口令和主机密钥记录。Base64 仅作为字段编码，不承担加密。
- 两种模式分别保留直连地址和 SSH 设置，Music Tag 账号及目录映射共用。
- 配置移除会删除存储记录；未确认的写入日志保留，防止重复提交。
- Android 备份及设备迁移显式排除凭据 SharedPreferences 和 DataStore 文件。
- 使用时密码不可避免存在于进程内存中；此方案不承诺抵御已被控制的设备或可靠擦除 Kotlin String。

## 网络与依赖

`MusicTagConnection.withClient` 管理 SSH 会话、回环监听和 HTTP 客户端，`MusicTagEditorConnection` 管理编辑页面的连接复用与空闲释放。使用随机本地端口并禁用隧道客户端的系统代理。业务回调保留调用方线程，保存前暂停播放器明确切回主线程。写请求继续禁用自动重试；保存结果不确定时保留日志并要求核验。写日志标识使用稳定的 SSH 服务地址，不能使用每次变化的本地端口。

SSH 使用 mwiede/JSch 2.28.7，Bouncy Castle 1.85.2 提供 Android 兼容算法。保留现代算法默认值，不启用 RSA/SHA-1 或跳过主机密钥校验。许可证随 APK 的 `assets/licenses/` 打包；R8 保留 JSch 通过类名加载的算法实现。

## 验证

- JVM 集成测试启动本地 SSH 和 HTTP 服务，验证首次信任、指纹变化、密码/加密私钥、Ed25519、并发隔离及释放。
- 连接管理测试覆盖复用、60 秒空闲计时重置、长时间保存与核验、离页延迟释放、重新进入、旧排队请求拒绝、失败释放及凭据变更；本地 SSH 测试验证认证复用、阻塞读取取消和业务回调线程。
- 配置测试验证旧 HTTP 配置迁移、模式切换、多行私钥和格式错误。
- Android 测试覆盖设置界面以及真实 Keystore 的往返、随机化密文和删除。
- 公网服务器联调须使用用户提供的 SSH 凭据和独立核实的主机指纹；本地测试不替代真实部署验收。
