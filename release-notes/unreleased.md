# 开发中更新 · 尚未发布

本页记录 v1.4.0 之后的源码改动。当前构建标识仍为 `1.4.0 / 11`，不代表这些功能已包含在公开安装包中；下一次发布前需确定新的版本名称并递增内部版本号。

## 分享与管理

- 支持分享单曲、专辑和歌单。歌曲使用更多菜单；专辑、歌单使用详情右上角分享按钮。
- 分享正文包含类型、名称、已知艺术家或歌曲数量、可选说明、收听链接及有效期；预览、复制分享内容与系统发送保持一致，保留“仅复制链接”。
- Android 系统分享面板附带封面预览，没有接入微信开放平台或微信原生卡片。
- 歌单创建时重新读取完整成员，保存实际提交数量。面板打开后发生增删、只剩一首的场景均不再沿用旧数量；空歌单或读取不完整时拒绝创建。
- “我的分享”位于“我的”歌单列表下方，仅在有记录时显示整个栏目；支持编辑说明、有效期和确认后撤销。

## 歌曲列表与详情

- 搜索、音乐库歌曲、专辑歌曲、艺术家歌曲和歌单歌曲统一行样式、右侧菜单位置与操作。
- 菜单顺序：添加到歌单 → 喜欢／取消喜欢 → 下一首播放 → 下载 → 分享歌曲 → 音乐标签 → 歌曲详情。
- 搜索不新增长按多选；其他原有多选操作保留，歌单中的重复歌曲按选中位置移除。
- 歌曲详情增加封面摘要与分组音频信息，适配深色、大字体和缺失字段。

## 曲库、标签与播放

- 调整发现页推荐组织与首页推荐入口，继续只使用当前账号曲库。
- 曲库、收藏、歌单和详情刷新减少重复请求与无变化写入，并保留必要的定期全量核对。
- 标签修改后的歌曲、关联专辑/艺术家、歌词、封面与播放元数据按同步结果刷新；增加同步状态反馈。
- 播放当前歌曲时保持已有队列与进度；系统媒体“上一首”的行为与应用内一致，并补充暂停队首、断网缓存和冷启动恢复验收。

## 验证

2026-09-24 原始验收：185 项单元测试和 137 项设备用例在处理测试环境及等待条件后最终通过，签名 Release 构建与模拟器冒烟通过。后续歌单数量修复另通过 app 111 项单元测试、新增 5 项快照设备测试及 2 项分享文案设备测试；后续修复未重新生成签名 Release。

完整范围、首轮失败及复测记录、发布版本号阻塞项见 [发布前验收报告](pre-release-2026-09-24.md)。微信接收端、真实服务器公网访问及真机兼容性仍需独立验证。
