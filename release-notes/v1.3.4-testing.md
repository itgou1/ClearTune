## 重点覆盖

- 最近添加：最新歌曲入库时间优先、旧专辑补歌、日期回退、30 天边界、删除新歌后的排序；新歌标记在深色主题、大字体和长标题下保持可见。
- 歌单：长按选择、收藏按钮不误触多选、空选择/全选、失败保留选择；批量写入、去重、新建歌单及写入成功但刷新失败的反馈。
- 封面：收藏与歌单列表图片、缺图回退；歌单详情封面元数据保留、小图先显示、高清替换和失败回退。
- 图片缓存：服务器/账号/尺寸键隔离；统一清理内存、磁盘、URL 缓存但保留离线封面；离线封面引用清理不影响其他账号。
- 下载：真实 WorkManager 执行、字节一致、关闭测试服务器后本地音频解码播放与本地封面；403 失败、503 自动重试、暂停/Range 续传/删除、旧任务拒写、孤立等待任务处理、历史下载补封面。
- 账号：实际界面退出再登录、队列重置、同 ID 的曲库/下载/待同步操作隔离、搜索历史与同步时间隔离；歌词时间文本回读及服务器/账号查询隔离；音频缓存键区分账号、服务器、歌曲和音质。
- 返回：左右侧在 15%、35%、80% 进度连续取消；完成返回、两个专辑及歌单详情独立；滚动位置、播放/下载回调、数据库更新、多选保护、后台失效不误退、账号结束拒绝迟到响应。
- 周边：首页卡片操作、动效不重复、中文登录界面、曲风流派搜索和音乐库清理一致性。

## 环境及验收边界

- Windows 宿主；无窗口 Pixel 8 模拟器，Android API 37（android-37.1 镜像）、x86_64、16 KB 页大小；Debug 包。
- 使用只读临时实例、临时账号数据库、设备内 HTTP 测试服务器和静音 WAV，不连接用户的实际音乐服务器。测试环境退出后清理。
- 预测返回使用回调注入，不验证小米系统对物理滑动的提交/取消阈值。
- 不等同于小米 15 Pro / HyperOS 真机验收、真实服务器全格式验证、计费 Wi-Fi 切换、系统省电杀后台、长期缓存压力测试或混淆 Release 的端到端测试。

## 复现

先在没有真实账号的专用模拟器安装当前 Debug APK 及对应 androidTest APK，再运行：

```text
gradlew testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :core:database:assembleDebugAndroidTest :app:lintDebug
adb shell am instrument -w -r -e notClass com.cleartune.app.DocumentationScreenshotsTest com.cleartune.app.test/androidx.test.runner.AndroidJUnitRunner
adb shell am instrument -w -r com.cleartune.core.database.test/androidx.test.runner.AndroidJUnitRunner
```

下载测试的前提与限制见 [下载回归说明](../app/src/androidTest/DOWNLOAD_TESTING.md)。不要在登录了真实账号的设备上执行清理操作或运行测试夹具。
