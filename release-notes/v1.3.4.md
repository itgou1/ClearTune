## ClearTune 1.3.4 · 歌单操作与离线封面优化

### 最近添加，更贴近曲库变化

- 首页按专辑内歌曲的最新入库时间排列“最近添加”，老专辑补充新歌也会前移；缺少歌曲时间时回退到专辑入库时间。
- 专辑内近 30 天入库的歌曲显示“新加入”标记，不改变原有曲序，也不在首页卡片增加数量提示。

### 批量加入歌单

- 音乐库歌曲、专辑和艺术家歌曲列表支持长按进入多选，不增加常驻多选按钮。
- 支持全选、加入已有歌单或新建歌单，自动跳过重复歌曲；添加失败时保留选择，方便重试。
- 多选期间收起迷你播放器，音乐继续播放，退出选择后恢复。

### 封面显示与离线保存

- “我喜欢的音乐”和歌单歌曲列表改用专辑封面，缺图时显示默认封面。
- 修复歌单列表有封面、进入详情却显示默认图的问题；详情接口未返回封面时保留已有封面信息。
- 歌单头图可先显示缓存小图，再自动替换为高清图；高清加载失败时保留小图。
- 图片缓存按服务器、账号和尺寸隔离；统一清理图片与临时缓存，不删除离线音频、离线封面或歌词。
- 下载歌曲时保存离线封面，已有下载按下载网络设置后台补齐。封面失败不影响音频下载；共用封面在没有下载任务引用后才清理。

### 返回与状态稳定性

- 专辑、艺术家和歌单详情按页面实例隔离数据与加载任务，修复返回手势取消后详情被上一页数据覆盖的问题。
- 返回预览不会清空当前页多选项；后台页面内容失效时，不再误退当前页面。
- 页面退出或账号结束后取消对应任务，阻止迟到响应更新已失效页面；现有返回动画与布局保持不变。

### 安装与升级

- Android 8.0 及以上；版本号 **1.3.4**，内部版本号 **9**。
- 下载 `ClearTune-v1.3.4.apk`，沿用此前正式版签名，可覆盖安装，无需卸载。
- 从 1.3.3 升级沿用现有账号数据库和离线音频，不要求重新下载；首次封面加载可能重新请求，历史离线歌曲的封面按网络设置补齐。
- 从 1.3.2 及更早版本升级仍适用 1.3.3 的账号隔离迁移提醒：旧版无法确认归属的本地数据不会自动迁移或读取，建议先联网同步尚未完成的修改。
- Debug 版与正式版签名可能不同，请勿为升级贸然卸载。

### 验证情况

- 发布前完成 **115 项单元测试 + 64 项设备测试**，全部通过，无失败或跳过；静态检查无错误，有 34 项既有警告。
- 设备测试基于 Debug 模拟器和本地测试服务器，不代表已完成小米真机、真实服务器全部音频格式、系统省电杀后台或混淆 Release 的端到端验收。
