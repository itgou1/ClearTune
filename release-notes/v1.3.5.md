## ClearTune 1.3.5 · 离线播放与操作体验修复

### 离线播放更可靠

- 播放优先使用有效的已下载文件；发现文件缺失或大小不完整时，不再把它当作可用下载。
- 断网时优先使用当前音质缓存；当前音质缓存不完整，而其他音质有完整缓存时，自动使用完整缓存播放。
- 保留账号上次使用的移动网络音质策略，避免断网后误切到 Wi-Fi 原始音质，重新启动后也能沿用。
- 不同服务器、账号和歌曲的缓存继续隔离；切换缓存音质后，拖动进度或恢复网络不会混用不同音频格式的数据。
- 修复网络请求失败后，恢复网络再点击播放或队列歌曲没有真正重试的问题。

### 返回与播放操作更一致

- 返回手势松手并由系统确认后才切换页面，取消手势时保持当前页面和选择状态。
- 耳机与系统媒体控制的“上一曲”直接切到上一首，与手机按钮一致；播放超过 3 秒也不会只重播当前歌曲。
- 保留顺序、列表循环、单曲循环和随机模式的队列行为；顺序播放到第一首时，上一曲不会把当前进度归零，也不会恢复暂停中的音乐。
- 移除每次点歌出现的“正在准备播放”提示；播放失败时仍提供反馈，避免同一错误状态反复提示。

### 安装与升级

- Android 8.0 及以上；版本号 **1.3.5**，内部版本号 **10**。
- 下载 `ClearTune-v1.3.5.apk`，沿用此前正式版签名，可覆盖安装，无需卸载。
- 从 1.3.3 / 1.3.4 升级沿用账号数据、下载、设置和播放队列。
- 从 1.3.2 及更早版本升级，仍适用 1.3.3 的账号隔离迁移规则：旧版无法确认归属的本地数据不会自动迁移，请先联网同步尚未完成的修改。
- Debug 版可能与正式版签名不同，请勿为升级贸然卸载。

### 验证范围

- 发布前本地全量 **115 项单元测试通过，无失败或跳过**；全部模块静态检查通过，无错误。
- 修复代码已完成针对性模拟器验收：缓存离线重播、恢复网络后手动重试、下载后关闭服务器并重启、短时后台和灭屏播放、连续切歌与队列修改，以及原始 v1.3.4 正式包到修复候选包的保留数据覆盖安装。
- 耳机上一曲修复的 3 项系统媒体命令回归通过，覆盖 5 秒进度、连续操作、四种播放模式和暂停边界。
- 发布流程对最终 1.3.5 源码执行全部单元测试、静态检查和签名 APK / AAB 构建。
- 实体蓝牙耳机、真实运营商弱信号、缓冲耗尽后的自动续播和厂商系统长时间后台限制仍需真机验证；模拟器结果不代表这些场景已全部验收。
