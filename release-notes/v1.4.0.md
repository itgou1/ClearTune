# ClearTune 1.4.0 · 音乐标签与播放体验

### 音乐标签

- 可在设置中连接自行部署的 Music Tag Web，并为 Navidrome 音乐库配置文件目录映射。在音乐库的歌曲菜单或主播放器更多菜单打开“音乐标签”。
- 支持读取和编辑单曲原文件标签，也可以刮削候选资料，挑选字段后统一保存。保存前核对原文件是否变化，只提交实际修改的字段；未保存内容可在当前会话内保留为草稿。
- 文件保存和服务器曲库刷新分别显示结果。写入结果不确定时可以检查读回内容，避免重复写入；封面无法由 Music Tag V1 自动校验时，提供图片对照确认。
- Navidrome 返回虚拟歌曲路径时，使用当前账号按歌曲 ID 查询实际文件路径；读取失败会显示具体错误和目标路径，不根据标题猜测文件。
- 标签更新后重新获取歌词、封面和播放元数据，避免沿用旧缓存。已下载音乐是独立文件，修改原文件后可按需重新下载。

### 歌词与标题

- 修复空歌词被长期缓存的问题：空结果会重新查询；已有歌词先显示缓存，超过 24 小时再后台更新。歌词界面右下角“⋯”提供手动刷新，失败时保留已有歌词。
- 主播放器、歌词界面和迷你播放器统一使用单行标题。仅播放中且标题超出时缓慢滚动；暂停保留滚动位置，继续播放接着滚动，切歌重新从头停留后开始。主播放器长按标题可查看完整信息。
- 其他歌曲列表、专辑网格卡片及专辑和歌单详情标题保持原有排版。

### 安装与使用

- 适用于 Android 8.0 及以上；版本号 **1.4.0**，内部版本号 **11**。
- 从此前正式版覆盖安装即可保留账号、设置、下载和播放队列；请使用正式版 APK，Debug 安装包的签名可能不同。
- Music Tag 服务是可选功能，需要用户自行部署并授予其音乐文件访问权限。当前仅支持单曲修改，不支持清空标签、重命名或批量改写。建议先在一首可验证的歌曲上核对目录映射与写入结果。

### 验证范围

- 发布前本地 161 项单元测试通过，无失败或跳过；全部模块静态检查通过，调试应用与 Android 测试包构建成功。发布流水线会对最终提交重新执行测试、静态检查并构建签名 APK / AAB。
- 长标题停留、滚动、暂停、恢复与切歌重置已通过隔离模拟器界面测试。Music Tag 的编辑与设置界面有自动化测试，但本次没有在用户的真实音乐库中执行标签写入；请先在可核对的单曲上验证服务挂载与目录映射。
