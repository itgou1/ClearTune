# ClearTune 1.5.0 · 音乐分享与统一歌曲操作

## 分享歌曲、专辑与歌单

- 单曲从更多菜单分享，专辑与歌单从详情页右上角分享。
- 可以填写推荐说明，并选择 1、7 或 30 天有效期。
- 分享前预览完整文案，包含作品类型、名称、已知艺术家或歌曲数量、说明、收听链接及有效期。复制分享内容与系统发送使用同一份正文，另保留“仅复制链接”。
- Android 系统分享面板附带封面预览；未接入微信开放平台，不提供微信原生封面卡片。
- 歌单按生成链接时重新读取的完整成员创建分享，保存实际提交数量。面板打开后增删歌曲、只剩一首时，生成后的摘要、文案和管理页保持一致；空歌单或读取不完整时不会创建链接。
- “我的分享”放在“我的”歌单列表下方，有分享才显示整个栏目；可编辑说明、有效期或确认后取消分享。

分享需要服务器支持并启用相应功能。接收者仍需能访问你的音乐服务器；分享不会自动让内网地址具备公网访问能力。取消系统发送不会删除已创建的链接。

## 统一歌曲操作与详情

- 搜索、音乐库歌曲、专辑歌曲、艺术家歌曲和歌单歌曲统一行样式、右侧菜单位置及操作顺序。
- 菜单顺序为：添加到歌单 → 喜欢／取消喜欢 → 下一首播放 → 下载 → 分享歌曲 → 音乐标签 → 歌曲详情。
- 搜索不新增长按多选；其他原有多选操作保留，歌单里的重复歌曲按选中位置移除。
- 歌曲详情增加封面摘要与分组音频信息，支持深色主题、大字体滚动及缺失字段提示。

## 曲库与播放改进

- 调整发现页推荐组织与首页推荐入口，推荐仍只来自当前账号曲库。
- 减少曲库、收藏、歌单与详情的重复刷新及无变化写入，保留必要的定期全量核对。
- 标签修改后按同步结果刷新歌曲、关联专辑/艺术家、歌词、封面与播放元数据，并完善同步状态反馈。
- 再次选择当前歌曲时保持已有队列与进度；系统媒体“上一首”与应用内行为一致。

## 安装与验证

- Android 8.0 及以上；版本 `1.5.0`，内部版本号 `12`。使用既有正式签名，可覆盖升级已发布版。
- 发布前基线验收包含 185 项单元测试和 137 项设备用例；歌单数量修复另通过新增 5 项快照设备用例及 2 项分享文案设备用例。首轮环境问题、测试等待修正与复测范围见 [验收报告](https://github.com/itgou1/ClearTune/blob/v1.5.0/release-notes/pre-release-2026-09-24.md)。
- 微信实际接收排版、真实服务器外网访问和各厂商真机兼容性未由模拟器验收替代。
