# ClearTune 1.5.2 · 网络电台与播放体验

适用于 Android 8.0 及以上；版本 `1.5.2`，内部版本号 `15`，沿用既有正式签名。

- 修复播放失败后恢复未播放的新队列时，旧音源错误残留在播放器上的问题；恢复队列仍不会提前请求音频。

- 首页改为左侧“常听精选”、右侧“网络电台”，使用统一的双封面卡片和清新人像／收音机封面。
- 新增网络电台列表页，读取当前服务器电台，支持播放、切台、暂停、刷新及失败重试；底部播放器同步显示直播状态。
- 电台直播绕过音频磁盘缓存，暂停时断开连接，恢复时重新连接直播；不提交歌曲收听记录，不覆盖原有歌曲队列。

- 添加到已有歌单后核对服务器实际歌曲列表；未保存或暂时无法确认时不再误报成功。重复添加明确提示“歌曲已在歌单中”，保留原有排序位置。

- 播放队列每行改为“更多＋拖动”；更多菜单依次为下一首播放、添加到歌单、喜欢／取消喜欢、歌曲详情、从播放队列移除。当前歌曲隐藏下一首播放，移除操作保留撤销。

- 主播放器“更多”按添加到歌单、查看专辑、查看歌手、下载歌曲、分享歌曲、音乐标签、歌曲详情排列。支持加入已有歌单或新建歌单，显示下载状态；缺少专辑或歌手关联信息时禁用跳转，菜单可滚动。

- 有效收听后立即更新本地最后播放时间，“好久不见”不再等待服务器同步；曲库刷新保留本地较新的有效收听记录，并利用已保存的历史记录修正旧时间。
- 收听记录先保存再上报；启动播放器或再次产生有效收听时补传失败记录，保留原始收听时间。

- 搜索结果显示后，后台核验只存在于本地结果中的歌曲；服务器明确确认歌曲不存在时，自动清理旧记录与搜索索引。
- 播放失败后按歌曲 ID 复查；确认歌曲已移除时清理本地曲库及播放队列，并提示原因。网络、权限、格式错误和普通 HTTP 404 不触发删除，不按歌名合并不同版本。



- 电台小播放器可展开独立播放页，采用新的人像耳机封面；支持暂停／继续、上一／下一电台和电台列表，隐藏均衡器、歌曲进度与歌曲专属操作。小播放器与系统媒体通知同步使用新封面。
- 电台列表入口移至播放器右上角，封面缩小、直播提示简化；音乐与电台共用播放控制组件，统一按钮尺寸、图标和深灰紫配色，并适配深色主题。

## 验证范围

- 发布前通过 208 项 JVM 单元测试和 179 项不同设备测试，多轮重跑不重复计数；Debug Lint 无错误。
- 本地模拟直播验证暂停断连、恢复重连、切台释放旧连接、后台播放及不提交歌曲收听记录。
- 验证了断网重试、下载、缓存、锁屏／后台播放、杀进程后服务器不可用时的离线恢复，以及电台深色／小屏／大字体界面。
- 设备测试基于 Android API 37 模拟器；真实标签服务写入、其他 Android 版本、各厂商后台限制及真机蓝牙／听感未在本轮覆盖。
