# ClearTune 1.5.3 · 电台直播与刷新体验优化

适用于 Android 8.0 及以上；版本 `1.5.3`，内部版本号 `17`，沿用既有正式签名，可覆盖升级并保留数据。

- 新增 HLS 电台直播支持，播放列表和音频分片直接连接直播源，绕过歌曲磁盘缓存；暂停后恢复时重新连接直播。
- 优化电台列表加载：已有列表后台静默刷新，首次加载超过 0.8 秒才显示文字提示，移除短暂闪现的横向进度条和顶部加载转圈。
- 电台更新按 ID 合并，保留已有顺序和滚动位置，仅更新变化内容；新增电台追加到末尾，增删平滑过渡。
- 刷新失败时保留已有列表，底部提示并支持重试，不挤动列表；首次加载失败也可重试。
- 修复开启均衡器后冷启动首次播放的音效初始化时序：提前绑定音频会话，等待保存的参数就绪后开始播放，并平滑应用参数。等待期间暂停或停止会取消播放请求，不通过静音播放消耗歌曲开头。
- 调整歌单“最近添加”排序：优先采用服务端入歌单时间，缺失时使用歌曲入库时间；原生与定制 Navidrome 使用同一规则，不再使用本机添加记录兜底。时间相同保持歌单原顺序，两个时间都缺失时放在末尾。

电台列表由所连接的服务器提供，本次客户端支持直接播放 HLS，不内置固定电台目录。

## 验证范围

- 222 项 JVM 单元测试、56 项 Android API 37 模拟器设备回归通过，覆盖电台延迟提示、后台刷新失败时列表位置保持、歌单排序和持久化、均衡器初始化、离线音频缓存及官方 HLS 播放与重连。
- Debug Lint：0 错误、60 条警告；正式 APK/AAB 构建通过。
- 正式 APK 与 v1.5.2 签名一致；模拟器通过从官方内部版本号 16 到 17 的覆盖安装，首次安装时间保持不变，新版冷启动正常。
- 模拟器测试以无窗口、无声音方式运行。各厂商后台限制及真机外放／蓝牙听感未在本轮覆盖，均衡器首次播放的实际爆音改善仍需真机确认。
