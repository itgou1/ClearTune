# ClearTune 1.6.0 · SSH 标签管理与播放修复

适用于 Android 8.0 及以上；版本 `1.6.0`，内部版本号 `18`，沿用既有正式签名，可覆盖升级并保留数据。

- Music Tag / WebTag 新增 SSH 加密隧道，支持密码和私钥认证、首次主机指纹确认及后续严格校验。SSH 失败不会降级为 HTTP；原有 HTTP/HTTPS 直连及旧配置继续可用。
- 编辑标签期间复用连接，操作结束后空闲 60 秒断开。离开编辑页释放连接；正在保存和核验时等待操作完成再释放。配置测试完成后立即断开。
- SSH 密码、私钥及口令继续通过 Android Keystore 加密保存，备份排除凭据。设置页支持修改、移除配置，明确区分“配置已验证”与当前连接状态。
- 修复标签保存的线程切换问题，暂停播放器在主线程执行；保留保存日志和回读核验，避免结果不确定时重复写入。
- 修复蓝牙和系统媒体按键无法切换网络电台：后台持有电台清单，上一台／下一台按顺序循环，支持暂停后切台，不依赖当前页面。
- 修复开启均衡器后冷启动首次播放的短暂音量突增窗口；初始化及音频会话重建期间，待音效参数和音量衰减准备完成后放行输出。

SSH 模式仅用于 Music Tag 标签管理；Navidrome 保持现有 HTTP/HTTPS 连接方式。SSH 隧道不会自动关闭服务原有的公网 HTTP 入口。

## 验证范围

- 发布前完整 JVM 回归 246 项通过，5 项需显式启用的公网诊断跳过；电台媒体控制与音频启动的 5 项 Android 设备回归通过。
- Debug Lint 0 错误、60 条警告；正式 APK/AAB 构建通过，补齐 SSH 库未启用的桌面可选依赖混淆规则。
- 正式 APK 与 1.5.3 签名一致，模拟器从内部版本号 17 覆盖升级至 18，首次安装时间保持不变。
- JVM 测试覆盖连接复用、空闲释放、保存与核验保护、离页处理、取消、凭据迁移及业务回调线程。
- Android 模拟器的真实 APP 界面连接实际服务器，验证编辑复用、约 60 秒空闲断开、离页释放，以及保存、回读和曲库同步；测试歌曲已恢复。
- 在 SSH 建连过程中强制关闭 APP 后，连接释放；重开保留配置，再进入编辑页可正常读取。该项不等同于写入过程中强杀测试。
- 长操作保护另通过真实服务器连接与延迟核验验证；界面保存按实际服务器速度完成，未注入超过 60 秒的单次 HTTP 请求。
- 模拟器无法替代不同手机及蓝牙设备的实际听感验收。
